# Start here

Every session: read `state.md` first. It says where we are.
Read deeper (a project's own `state.md`, its changelog, the idea bucket) only when the task needs it.
Never load raw logs, transcripts or old snapshots into the context. Read the state; go to the source only when you need it.

At the end of a session:
- update `state.md`: active thread, next step, what's blocked. Replace, don't append.
- add a dated entry to `changelog.md`: what happened.
