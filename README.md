# Brain starter

Plain text files. Works with any AI agent that can read a folder.

1. Fill in `state.md` and keep `changelog.md` going (step 1).
2. One folder per project under `projects/` (step 2).
3. Every idea goes into `ideas/`, every bug into `backlog.md` (step 3).
4. Write your own rules into `CLAUDE.md` as you go (step 4).
5. Only then: skills and tools (step 5).

Not using Claude? `AGENTS.md` points every other agent (Codex, Gemini CLI, local models) to the same rules.
Click **Use this template** on GitHub, or download the ZIP, and start with `state.md` tonight.

From the Laconova Labs video "Build your brain before your tools".
